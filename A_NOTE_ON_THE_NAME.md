# A Note on the Name

If you've found yourself wondering why this repository is named **`donotusethis`**, you're not alone.

At first glance, it looks like a warning. Or perhaps an abandoned experiment. In truth, it is a little bit of both—and neither.

## Why "donotusethis"?

The name began as a placeholder, the sort of thing developers often write when they don't expect a project to become important.

Then something interesting happened.

The repository stayed. The name stayed. And over time, it started to mean something.

## An Invitation, Not a Warning

The phrase **"do not use this"** is not meant to discourage you from reading these notes.

Instead, it is a reminder not to treat them as unquestionable authority.

These are working notes—ideas collected from talks, books, conversations, and experiments. They are intended to be explored, questioned, challenged, and improved.

In that sense, the repository name reflects an epistemic principle:

> Just because something is written down doesn't make it true.
>
> Just because it is published doesn't make it complete.

Knowledge deserves scrutiny.

## Reverse Psychology?

Perhaps.

There is a certain irony in naming something "donotusethis." It invites curiosity.

People click it precisely because they're told not to.

Maybe that's part of the fun.

## A Repository That Refuses to Be Finished

Like many long-lived software projects, this repository was never really "done."

It continues to evolve with every conversation, every correction, every better question.

The name is a reminder that certainty is temporary.

## In the Spirit of Fulmo Talk Series

The Fulmo Talk Series exists to encourage thoughtful exploration rather than unquestioning acceptance.

This repository follows the same philosophy.

Don't use these notes as conclusions.

Use them as starting points.

Question them.

Improve them.

Replace them when you find something better.

And if you do, you've understood the name perfectly.
